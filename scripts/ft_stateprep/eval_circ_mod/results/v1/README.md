# Results of arXiv v1 (superseded)

These are the simulation results and the figure of the first arXiv submission (arXiv:2601.13313v1).
Those simulations did not prepend resets, so the initialization noise was not applied.
They are superseded by the results in `results/*_{x,z}.csv`, which are the ones reported in the published paper
(Phys. Rev. A, doi:10.1103/y9ln-b4t9).

The circuits in `circuits/*_v1/` are older circuit versions from the same period.
